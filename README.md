# بەرنامەی دیسکتۆپی Pic_Qaza (Microsoft SQL Server)

ئەم ئەپڵیکەیشنە سیستەمێکی ویندۆز دیسکتۆپە بۆ بەڕێوەبردن، ئەرشیفکردن و تۆمارکردنی وێنەی پسووڵەکان بە کەمترین قەبارە و بەرزترین کوالێتی، بەستراوەتەوە بە **Microsoft SQL Server 2019** لەسەر سێرڤەری **NAZHAD**.

---

## ✨ تایبەتمەندییە سەرەکییەکان

1. **فایلی دامەزرێنەری سەربەخۆ (Setup Wizard):**
   - فایلی `Setup_Pic_Qaza.exe` بە شێوازی ویزارد بە زمانی کوردی هەموو فایلەکان لەسەر کۆمپیوتەری یوزەر دادەمەزرێنێت و شۆرتکەت لەسەر دیسکتۆپ دروست دەکات.
2. **ئایکۆنی مۆدێرنی 3D:**
   - ئایکۆنی تایبەتی `app.ico` بۆ ئەپڵیکەیشن، شۆرتکەت و تاسک بار.
3. **چاپکردنی پسووڵە بە قەبارەی A5 (نیو پەڕەی A4):**
   - دوگمەی چاپی تایبەت بۆ ڕێکخستنی وێنە و زانیارییەکانی پسووڵە بەپێی ستانداردی وەرەقەی A5 بێ هیچ وەتەرمارک یان نووسینی زیادە.
4. **هاوکاتکردنی کات لەگەڵ کاتژمێری کۆمپیوتەر:**
   - ستوونی **(کات)** بە دروستی کاتی تۆمارکردن پیشان دەدات هاوتا لەگەڵ کاتژمێری ناوخۆیی کۆمپیوتەر.
5. **خێرایی و کەمکردنەوەی لۆدی سێرڤەر:**
   - خشتەکە بە شێوەی خۆکار تەنها پسووڵەکانی ئەمڕۆ پیشان دەدات، لە کاتی گەڕانیشدا دەچێتە ناو هەموو ئەرشیفی مێژوویی.
6. **کۆنترۆڵی دەسەڵاتەکان (Admin / User):**
   - بەشی بەکارهێنەران، زانیاری سێرڤەر، و دوگمەی سڕینەوەی داتا تەنها بۆ بەڕێوەبەری سەرەکی (Admin) بەردەستە.

---

## 📌 زانیاریەکانی پەیوەندی داتابەیس (Database Connection)
- **سێرڤەر (SQL Server):** `NAZHAD` (یان `localhost`)
- **بنکەی دراوە (Database):** `Pic_Qaza`
- **بەکارهێنەری SQL:** `sa`
- **پاسۆردی سێرڤەر:** `Na2652014Va`

---

## 🖼️ تەیبڵی وێنەکان (`QazaImages` Table)
تەیبڵی `QazaImages` لەناو داتابەیسی `Pic_Qaza` دروستکراوە بەم تایبەتمەندیانە:
1. `Id`: ناسنامەی سەرەکی (Primary Key)
2. `SerialNo`: **زنجیرە** (خۆکارانە زیاد دەبێت 1, 2, 3...)
3. `ReceiptNo`: **ژمارەی پسووڵە** (NVARCHAR)
4. `ReceiptDate`: **بەروار** (DATE)
5. `CreatedAt`: **بەروار و کاتی تۆمارکردن** (DATETIME - GETDATE())
6. `ImagePath`: **ناونیشانی وێنە** لە سێرڤەردا
7. `ImageSizeKB`: **قەبارەی وێنە بە کەمترین کیلۆبایت** (FLOAT)
8. `RegisteredBy`: **ناوی یوزەری تۆمارکردن**

---

## ⚡ تەکنەلۆژیای کەمکردنەوەی قەبارەی وێنە (Smart Compression)
- وێنەکان پێش ناردن بۆ داتابەیس ئۆپتیمایز دەکرێن بە کوالێتی بەرز (Full HD 1080p).
- قەبارەی وێنەکان لە چەندین مێگابایت (MB) دەهێنرێتە خوارەوە بۆ نێوان **80 تا 250 کیلۆبایت (KB)**، واتە زیاتر لە **85% بۆ 90%** قەبارەی وێنە کەم دەبێتەوە بێ ئەوەی کوالێتی و ڕوونییەکەی کەم بێت!
- دەتوانیت وێنەکە ڕاستەوخۆ بە **Drag & Drop** یان **Ctrl + V (Paste)** لە کلیپبۆردەوە دابنێیت.
