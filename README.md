## 🖼️ تەیبڵی وێنەکان (`QazaImages` Table)
تەیبڵی `QazaImages` لەناو داتابەیسی `Pic_Qaza` دروستکراوە بەم تایبەتمەندیانەی داوات کردبوو:
1. `Id`: ناسنامەی سەرەکی (Primary Key)
2. `SerialNo`: **زنجیرە** (خۆکارانە زیاد دەبێت 1, 2, 3...)
3. `ReceiptNo`: **ژمارەی پسووڵە** (NVARCHAR)
4. `ReceiptDate`: **بەروار** (DATE)
5. `CreatedAt`: **بەروار و کاتی تۆمارکردن** (DATETIME - GETDATE())
6. `ImagePath`: **ناونیشانی وێنە** لە سێرڤەردا
7. `ImageSizeKB`: **قەبارەی وێنە بە کەمترین کیلۆبایت** (FLOAT)
8. `RegisteredBy`: **ناوی یوزەری تۆمارکردن** (ناوی ئەو بەکارهێنەرەی لە لۆگین داخڵ بووە)
